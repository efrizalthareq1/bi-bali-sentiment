Tutorial: Membuka & Menjalankan Sentimen KPwBI Bali

Panduan untuk membuka file ZIP source code dan menjalankan dashboard secara lokal (Windows).
Demo online: https://bi-bali-sentiment.vercel.app

Ringkas untuk atasan: ekstrak ZIP → install Python + Node.js → jalankan backend di port 8000 → jalankan frontend → buka http://localhost:3000. Atau langsung buka link demo online di atas tanpa install.

1. Isi ZIP

ItemKeterangan
frontend/Dashboard (Next.js / TypeScript)
backend/API & analisis sentimen (Python / FastAPI)

Folder berat seperti node_modules dan virtual environment Python tidak disertakan; dibuat saat instalasi.

2. Prasyarat

  1. Python 3.11/3.12 — python.org (centang Add to PATH)
  2. Node.js 18/20 LTS — nodejs.org
  3. Opsional: Visual Studio Code
python --version
node --version
npm --version

3. Membuka ZIP

  1. Klik kanan file ZIP → Extract All…
  2. Buka folder hasil ekstraksi
  3. Pastikan ada folder frontend/ dan backend/

4. Menjalankan Backend

cd PATH\KE\FOLDER\EXTRACT\backend
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
copy ..\.env.example .env
uvicorn app.main:app --reload --port 8000

Cek: http://localhost:8000/health · Docs: http://localhost:8000/docs

Jangan tutup jendela PowerShell backend selama demo.

5. Menjalankan Frontend

Buka PowerShell baru:

cd PATH\KE\FOLDER\EXTRACT\frontend
npm install

Buat file frontend\.env.local:

NEXT_PUBLIC_API_URL=http://localhost:8000
npm run dev

Buka browser: http://localhost:3000

6. Cara Menggunakan

  • Dashboard — ringkasan sentimen, tren, platform, word cloud, tabel, SNA Graph
  • Filter — platform, sentimen, keyword, tanggal, pencarian teks
  • Generate Dummy Data — data contoh jika database kosong
  • Sumber Data — sync berita / konektor medsos / upload CSV

Sentimen: Positif (mendukung), Negatif (kritik), Netral (informatif).

7. Alur Demo Singkat

  1. Jalankan backend + frontend
  2. Buka http://localhost:3000/dashboard
  3. Generate Dummy Data atau sync Berita
  4. Tunjukkan ringkasan, grafik, tabel, dan SNA Graph
  5. Filter keyword: Bank Indonesia, inflasi, QRIS, GPIPS
